# Sources

Shared by the client on 2026-10-23 as video transcripts, distilled by five reader agents and paraphrased here. No transcript text is stored in the repo.

- **Harvard CS50, Introduction to Computer Science** (David J. Malan; the full ~24-hour lecture series as published on the freeCodeCamp channel). Used for: problem-solving method, abstraction and design, correctness and edge cases, numbers and limits, memory and resources, data structures and Big-O, debugging, testing, SQL and data modelling, web/HTTP, security (injection, client-side trust, sessions), concurrency, and AI-assisted programming.
- **A senior software system design course** (a five-step framework with worked designs of Spotify-, Booking.com- and WhatsApp-like systems). Used for: the design method, NFRs as numbers, estimation, data modelling, consistency, idempotency, queues, caching, reliability and failure handling, and the local-vs-distributed split.

Language-specific details from the courses (C syntax, Flask, Python idioms) were translated into Eucas's TypeScript/Electron/SQLite equivalents. Course logistics, jokes, quizzes and distributed-only infrastructure details were dropped. Statistics quoted in the courses are illustrative.
