# Sources

Eight design-education video transcripts the client shared on 2026-10-22, paraphrased. Sponsor segments and agency sales pitches were removed. Statistics are the videos' claims and have not been verified here.

| # | Topic | What we took |
|---|---|---|
| 1 | The "intelligence trap": stored value in the AI era (examples: an image generator's taste profile, a sleep wearable, a spend-management platform) | The intelligence layer, the investment loop, visible compounding, the exit question, automatic deposits → [intelligence-layer.md](intelligence-layer.md), with an ethical (exportable) framing |
| 2 | The commodity ceiling: what makes a product feel premium | Evidence of quality (status, undo, next step), "design theater", cross-screen coherence, worst moments and the service-recovery paradox → [states-and-recovery.md](states-and-recovery.md) |
| 3 | A six-stage agency process (onboarding → discovery → UX → UI → emotional integration → delivery) | Pin emotional moments in UX, an obsessive UI QA pass, hand-off cleanup. It maps onto our existing lifecycle (phases 4–5) |
| 4 | Apple's design principles | Physics-based motion, subtle teaching cues, gradual change, squircles, remove-then-add-back, the three-tap rule, consistency and spatial continuity → [emotion-and-motion.md](emotion-and-motion.md) |
| 5 | Trial and paywall experiments | The certainty effect (one estimate, not a range), framing, progressive disclosure of what happens next, soft limits for power users. Bench has no paywall, so only the psychology applies |
| 6 | Designer levels on one screen (beginner → senior) | The rubric axes: copy, visuals, color, type, spacing. The "hidden mistake" is designing static images instead of an experience |
| 7 | Seven website guidelines (type, spacing, grids, breaking monotony, color, visuals, details) | Relationship spacing multipliers, line length, breaking the grid on purpose, restraint with details → [craft-checklist.md](craft-checklist.md) |
| 8 | Junior → staff screens (food list, real-estate filters) plus a UI/UX basics primer | Hierarchy test, control when there is no right default, consequences before commitment (counts on options), context in controls (histograms), the state set for buttons and inputs, icon = line height, tracking on headings, dark-mode depth |
