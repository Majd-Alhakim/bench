# Spike S-6: a deep link to "Other system tray icons" (first-run screen 6)

**Date:** 2026-10-26 · **Branch:** `spike/SP-ST1` · **Code:** none (read-only lookups)
**Setup:** Windows 11 Home 26300. Read the Settings app's own search index (`C:\Windows\ImmersiveControlPanel\Settings\AllSystemSettings_*.xml`).

**Verdict: provisional GO with limits; confirm by eye on the [manual checklist](G6-MANUAL-CHECKLIST.md).**

## Findings
- The list exists as setting **`SystemSettings_DesktopTaskbar_SystemTrayAppList`** on page **`SettingsPageTaskbar`** (group `SystemSettings_Personalize_Taskbar_Settings`). That's the "Other system tray icons" section.
- The index gives a deep link for the **page**, not for that **setting**. `ms-settings:taskbar` opens Taskbar settings; nothing in the index targets the section.
- **So:** first-run screen 6 opens `ms-settings:taskbar` and shows one step: "Open **Other system tray icons** and turn on **Eucas**". That's half of UX's numbered steps, and the link does the navigation.
- Since CR-011 the notch is the main surface and the tray is a fallback, so this screen matters less. It may only be needed when the notch is off.

## Manual check
Run `start ms-settings:taskbar`. Expect the Taskbar page, with "Other system tray icons" further down (collapsed). Record whether it's collapsed or open, and the Windows build.
