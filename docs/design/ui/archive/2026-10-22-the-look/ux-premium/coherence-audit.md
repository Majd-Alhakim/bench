# Coherence audit: direction v0.2, "use it for an hour"

Part of the [premium experience spec](README.md). Premium-craft gate 9: walk the core flows end to end as the client would and list every place where Bench stops feeling like one product. Each finding: **screen — rule — problem — fix**, most severe first. A finding names the rule it breaks (ui-ux-guide).

**Method.** Four walks through [`direction.html`](../../ui/prototype/direction.html) v0.2 (source read in full for the copy, data and tokens) and the renders in [`prototype/screens/`](../../ui/prototype/screens/):
1. **Morning triage:** Home → open the top ticket → resolve → the top bar and the sidebar counts → a project card → split view.
2. **A long-running task:** the sidebar → Noor → the workspace → the approval → take-over → routines → settings.
3. **The team:** team chat → a handoff → the debate → @mention → the roster.
4. **Creating:** New agent → New project → the sidebar → menus.

**Limits.** No shell was available in this session, so nothing was re-rendered. Five renders are still v0.1 (finding C-33); the v0.2 team chat and agent header were checked in source. **Severity:** **S1** breaks a decision or a requirement the client already approved · **S2** two patterns for one situation · **S3** polish and accessibility.

Totals: **9 S1 · 14 S2 · 15 S3 = 38.**

## What "fixed" looks like (the hour-long walk, v0.3)

- **Morning:** the top ticket is open with a decision that says what it does. Resolving it ticks every count at once, and the next ticket opens. The counts agree everywhere.
- **Long task:** the agent's header reads quietly. One approval card appears wherever you meet the request. Every receipt has the same format. Take-over grows out of the card and returns to it.
- **Team:** routing explains itself. The handoff chip moves the task. The debate has one blue decision and condenses into a memo.
- **Creating:** fields you can type into, a consequence on the button, a birth, a name that flies into the sidebar, and Undo.
- **Everywhere:** one corner family, one tag grammar, one time format, one crumb grammar, one status vocabulary.
