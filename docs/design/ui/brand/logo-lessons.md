# Logo lessons from the client's four videos (2026-10-24)

The client asked us to learn from these before improving the logo. Sources:
1. [The FULL Guide To Logo Design Rules (2026)](https://youtu.be/g2bSztQ_Q7g) (Satori Graphics): read from captions and frames.
2. [Michael Bierut on logos](https://youtu.be/RBTiTcHm_ac): watched by Gemini.
3. [10 logo design tips](https://youtu.be/gza5-1e0IY4) (Will Patterson): watched by Gemini.
4. [13 Golden Rules of Logo Design](https://youtu.be/T54ytwmlObg) (Satori Graphics): read from captions and frames.

Six rounds of new directions were explored and dropped; the client chose to keep Quartet and refine it (BRAND §6).

## What we take, and how Quartet uses it

| Lesson | Source | For Quartet |
|---|---|---|
| The voice sets the emotional temperature: a calm brand can't have a loud logo. | 1 | One colour (Ink, Porcelain) everywhere in the interface; the four hues only on the app icon and brand moments. |
| A logo is an empty vessel; meaning is poured in over time. Judge it on how it lasts. | 2 | Keep the idea; spend the effort on craft, not on a new idea. |
| The modern logo is often a system (MTV, Google Doodles, MIT Media Lab). | 2, 4 | Four seats, each one an agent shape: a system that can hold your own team later. |
| It must work without colour; colour enhances, never rescues. | 1, 4 | The Ink and Porcelain masters come first; colour is derived. |
| It has a second to register: blur it, shrink it, glimpse it. | 1, 2 | Tested at 16 px, squinted, in the taskbar and the browser tab. |
| Correct the eye, not the maths: points read small, squares read big, light on dark reads heavier, near-miss angles look like mistakes. | 3 | Even weights and gaps, overshoot on round shapes, a true 60° triangle, a shaved reversed mark (`logo/quartet.py`). |
| Logotype and mark speak the same language. | 4 | The lockup keeps Instrument Sans 600, the interface face. |
| Clear space comes from a part of the logo. | 3 | A third of the mark's height, as BRAND §6 sets. |
| Mirror test and reverse image search before delivery. | 3 | Mirror test done; reverse image search needs an upload and is a client step. |
| Ship a one-page README with the files. | 1 | Part of the logo kit, when it's made. |
