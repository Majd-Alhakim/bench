## What we take, and what it changes for Eucas

| Lesson | Source | What it means for the Euca wordmark |
|---|---|---|
| The voice sets the emotional temperature. A calm brand can't have a loud logo. List 5 words it would say, 5 it never would, and one sentence it would post. | 1 | Eucas is calm, candid, warm. Five bright colours read as a toy brand. **The default goes one colour; colour becomes a moment, not the logo.** |
| A logo is an empty vessel; meaning is poured in over time. Judge it on how it lasts, not the first splash. | 2 | Don't chase "wow". Chase something we can live with for years. |
| The modern logo is often a system with endless variations (MTV, Google Doodles, MIT Media Lab). | 2, 4 | Five characters with the app's expressions **is** a system: they blink, look, sleep, cheer. Design the rules, not only one frame. |
| It must work without colour; colour enhances and never rescues. | 1, 4 | The ink and porcelain versions are the masters. |
| It has a second to register at thumb speed; blur it, shrink it, glimpse it. | 1, 2 | The e alone is the icon. Test squint, 16 px and the taskbar. |
| Close the ownability gap: put 20 category logos side by side; most could swap places. | 1 | Nothing in AI tools has the Look. Keep it as the one ownable feature. |
| Not literal; memorable; one idea in one sentence. | 1, 4 | "The team spells its own name." |
| Logotype and mark must speak the same language. | 4 | The e icon is cut from the wordmark itself. |
| Correct the eye, not the maths. White on dark looks bigger (shave it); round ends pinch like a bone; perfect circles look stiff; kern tighter and optically. | 3 | Overshoot the round letters, make the bowls slightly wider than tall, space each pair by eye, and thin the reversed version. |
| Clear space comes from a part of the logo. | 3 | Clear space = the width of one eye-pair. |
| Mirror test and reverse image search before delivery. | 3 | Run the mirror test in the sheet; reverse image search is a client step (needs an upload). |
| Context first: see it in the real places before polishing. | 1 | Show taskbar, title bar, README header and dark mode, not a white page. |
| Always include one stretch idea. | 1 | Show one bolder variant beside the recommendation. |
| Ship a one-page README with the files. | 1 | The kit gets a usage page. |
