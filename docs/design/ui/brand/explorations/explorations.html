01

Logo directions

Six genuinely different ideas: a team, a glass box, a set of characters, a trace, a letter and a name. Each is shown on light and dark, as a macOS and a Windows icon, as a real 16 px favicon (with its pixels enlarged), and locked up with “bench”. No slanted eye-pair, no X shapes, no starbursts.

RecommendedA · SeatedIt draws exactly what Bench is (different agents, one team, sitting on one bench), it stays readable at 16 px, and it keeps working under any new name.
Rename test · 3, 5, 8 letters
02

Your brand colour, without the blue

Five non-blue palettes lead; the current Porcelain + Cobalt sits last as the baseline, because blue is what others use. Each palette is neutrals (canvas, surface, ink, secondary text, hairline) plus one action colour and the feedback colours, applied to the same screen. Every contrast ratio is computed live from the hex values (WCAG 2.2: 4.5:1 text, 3:1 UI parts). Agent hues are unchanged, Karim keeps Pear.

RecommendedBone + AubergineA colour almost nobody in software owns. It reads as yours, means nothing else in the interface (not done, not needs-you, not error), and stays calm for an all-day app.
03

Typefaces

Six pairings that fit calm, precise and warm, each set with real Bench copy: a headline, the inbox title, an approval, an agent line, usage numbers and a trace. All are SIL Open Font License 1.1, so the app can bundle them and render the same on Windows, macOS and Linux.

RecommendedInstrument Sans + JetBrains MonoPrecise like a grotesk, warm in its curves, and its 600 weight gives the wordmark a voice without looking like every other dev tool. OFL, both.
04

Sounds

Three sounds from one family, synthesised live in your browser (no files): soft, short (under 400 ms), pitched in the same key, and never alarming. A fourth, optional chime greets the first open of the day. In the app they are on by default, with a mute switch in Settings, and the OS’s Focus or Do Not Disturb silences them all.

RecommendedShip all three, chime off by defaultNeeds you, done and handoff carry information. The morning chime is pure delight, so it should be something you turn on, not something you get.
