# Client decisions: brand round 2 (2026-10-23)

Reviewed: the explorations page and boards B ("The Proof") and C ("Night Glasshouse") in `docs/design/ui/brand/explorations/`.

| Topic | Client (verbatim) | Decision |
|---|---|---|
| Brand direction and colours | "I would stick with current brand and colors" | **Keep the current brand** ("Your team, in plain sight", BRAND.md) with **Porcelain / Ink / Cobalt** (P-1, P-2 accepted as built). This supersedes the 2026-10-22 "brand colour must not be blue" note. Boards B and C stay as explorations only. Karim's hue: Pear (P-4) |
| Logo / app icon (B-2) | "I liked the logo of the quadrat the most" | **Logo = "Quartet"** (four character shapes in a 2×2) from the explorations page, for the mark, app icon, favicon and wordmark lockup. Replaces the "lit window" eyes mark |
| Typeface (P-3) | "the typography go with recommended" | **Instrument Sans (400/600) + JetBrains Mono**, both SIL OFL, bundled with the app. Replaces "the platform's own face". Check 13 px rendering on Windows/Electron |
| Sounds (P-7) | "the sounds are good" | **The explorations sounds as designed:** needs you (two rising notes), done (one settling note), handoff (a soft left→right breath); on by default with mute in Settings. The first-open-of-the-day chime is optional, off by default |
