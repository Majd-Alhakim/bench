# UI feedback 5: G4/G5 review of prototype v0.7.1 (2026-10-24)

The client reviewed v0.7.1 in the browser pane, with annotated screenshots. This is the client's first G4/G5 pass, so **G4 and G5 stay open** until v0.8 is reviewed.

| # | Client (condensed from the annotated screenshots) | Decision (PM) |
|---|---|---|
| UF5-1 | Team chat members list: *"I want to be able to see their titles next to their names here, also I want to be able to click on them and a small popup would open with a brief about this agent and I can go to chat with them go to profile and edit them"* | Each member row shows **name + title** (titles are optional, BR-12/F3). Clicking a member opens a **small agent card**: face, name, title, status, the one-line description, plus **Chat**, **Profile** and **Edit**. Esc or a click outside closes it. The same card works wherever a member list appears |
| UF5-2 | The composer scrolls inside with arrows: *"Instead of having like a scroll bar let it be an expand option with the prompt bar get larger when pressed, and at the same time the bar gets larger as I write more lines like claude and chatgpt"* (reference: Claude's composer with an expand ↗ button and an expanded editor) | Every composer **grows with the text** up to about 8 lines, with no inner arrows. Past 3 lines an **Expand** button appears (top-right); it opens a large editor in the same place, and **Collapse** brings it back. The draft is kept either way |
| UF5-3 | *"I want to be able to drag any part from the side menu and drop it in the middle and start a split view, I can split to max 4 parts"* | Any sidebar item (an agent, a team chat, a dashboard, Memory, Usage, Look inside) can be **dragged into the main area**. Drop zones appear (left / right / top / bottom), and the drop makes a split. **Up to 4 panes**; a fifth drop shows "4 is the most; close one first". Each pane has a close ×, and keyboard users get "Open in split" in the item's "…" menu |
| UF5-4 | *"How can i view the memory graph did you drop the idea?"* | **Not dropped.** It's in scope (Bench Memory, PRD Sprint 3: by keyword, by meaning and in the graph); the prototype never drew it. Memory gets a **List / Graph** toggle; the graph shows notes as nodes linked by their `[[links]]`, coloured by owner, and clicking a node opens the note |
| UF5-5 | *"I feel that the scroll bar style is not fitting the style of the app, it needs something more minimal and premium"* | One app-wide **minimal scrollbar**: a thin rounded thumb with no arrows and no track. It's faint at rest, brighter on hover and while scrolling, and the same in dark and light |
| UF5-6 | *"I couldn't review the onboarding from start like I just downloaded the app"* | A clear **"Start as a new user"** entry at the top of the demo bar. It resets the demo to a fresh install (empty sidebar, no projects, no memory) and runs the first-run flow from step 1. Finishing it lands on a first Home with only your main agent |

Source: the client's message of 2026-10-24 with seven annotated screenshots (Team chat roster; Noor's composer with inner scroll arrows; Claude's composer collapsed and expanded; Split view; Memory and its scrollbar).
