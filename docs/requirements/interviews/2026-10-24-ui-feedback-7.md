# UI feedback 7: split panes (2026-10-24)

From the client's review of v0.8.1, with an annotated screenshot of a 3-pane split. G4 and G5 stay open.

| # | Client | Decision (PM) |
|---|---|---|
| UF7-1 | *"when splitting screens making the size of the agent and the typing bar small is better for UX, cause the user can see the chat more clearly, and also removing the blur, I think maybe when splitting the agent should appear up as part of the header not on the screen so it is not blocking the text"* | In a split pane, the agent moves into the **pane header**: a small face with its status dot, the name, the status and the title. The big face, its sticky wash and the **blurred edge** are removed, so the chat starts at the top. The **message bar is compact** (smaller height and text, no hint line), and the floating screen/routines icon is hidden (open the agent full screen for that). Team chat panes drop their big "Team chat" title and keep the debate bar and members |
