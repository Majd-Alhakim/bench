# Grilling round 1: what could make Bench bad (2026-10-23)

Facts: [risk-facts-2026-10-23.md](../../research/risk-facts-2026-10-23.md).

| # | Question | Client (verbatim / condensed) | Decision |
|---|---|---|---|
| Q4 | Usage cap / pacing | "All other apps have the same problem … if your limit is finished then you have to wait … people use agents because they want to cut off waiting time and build what they can build right now … keep it as A no cap" | **No cap and no pacing.** Agents run as much as the work needs; when the plan's limit is reached, work waits for the reset (show it clearly) |
| Q8 | Tool for you or product | "consider it as a personal project that I built for me and I can share it with others and they can customize it as they want" | Personal project, shared openly; customisability matters more than polish for strangers |
| Positioning | vs Anthropic Cowork | "not a product to compete Anthropic … just a workspace extension to what they already have but for people who want to build software in a much organized way and less context switching between different chats … someone who has a Claude subscription can use all its benefit in Bench including Claude Cowork, but the only catch that Claude Code + Cowork are in one place as one agent" | **Bench complements Claude**: an organised workspace for building software with a team of agents, using everything the subscription offers (Claude Code, Cowork capabilities) in one place |
| Q10 | Runaway limits / Opus opt-in | "models are chosen automatically by the tasks that the agent will be doing … if an agent's only job is to write PRDs … Sonnet or Haiku will do the job" | **Model = chosen automatically per task** (light work → Haiku/Sonnet, heavy → Opus); no manual Opus opt-in. Other runaway limits: open (round 2) |
| Q11 | Laptop-closed work | Answered by the positioning: complement Anthropic | No own cloud runner; no competing with Cowork |
| — | Dark theme colour | "it looks more of purple than dark, make it actually dark charcoal color and grey" | Neutral charcoal/grey dark theme, no purple/blue cast |
