# Client feedback: direction v0.3, round 3 "calm" (2026-10-23)

Screenshots shared: composer send button while typing, New project "Goal"/"Describe it" fields, the new-agent draft (Lumen), Lumen's empty screen panel, and a Grok Bot agent panel as a reference (compact screen preview + routines, settings gear, close).

| # | Feedback (client, condensed; quotes verbatim) | Action |
|---|---|---|
| C1 | "when typing in the box the arrow colors becomes strange like it disappeared needs higher contrast here" | Send button with a draft: white/near-white arrow on the Ink fill (≥ 4.5:1); check every state |
| C2 | "The Handoff animation is not smooth as in the brand page" | Use the brand board's handoff motion in the prototype |
| C3 | "why this optional looks like this? make it just a small (Optional) beside the word Goal" | Optional fields: a small "(Optional)" after the label; no extra grey box |
| C4 | "I want to be able to change the new agent name" | The new-agent draft name is editable before Create |
| C5 | "keep the default that the screen menu is closed and when opened it displays its contact … screen, settings, and routines" + the Grok reference: opened from a screen icon, first shows a **compact screen preview** (click to enter and see what the agent is doing) with **routines under it**, and **settings** behind an icon next to it | Agent side panel **closed by default**; a screen icon opens it; panel = compact live screen preview (enter for full view) + routines below; settings via a gear; close button. No big empty-state boxes |
| C6 | "Make the home screen the chat with the main bot." On entry Atlas asks, e.g. "There are N things that need you. Want me to show them?" Clicking opens **a pop-up over the current screen** listing everything that needs you, with the same ticket actions; also reachable from the top-right "Needs you" | Home = Atlas chat. "What needs you" moves into an overlay opened from Atlas's question or the top bar |
| C7 | General: *"when you try to use it, you feel overwhelmed by many things that are appearing … Use the white spaces. Let the user, when it enters, feel relief, not feel stressed … all the colors, all the text, everything there and here … make it smooth and clean."* Apply the same logic everywhere | A **calm pass on every screen**: fewer simultaneous elements, compact/collapsed by default, progressive disclosure, more white space, less colour, less text; the first thing the user does is chat |
