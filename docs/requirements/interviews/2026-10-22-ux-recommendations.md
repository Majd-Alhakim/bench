# Client decision: UX premium recommendations R1–R11 (2026-10-22)

Client (verbatim): *"Also accept all the recommendition that the UX gave before"*. Source: [UX premium spec](../../design/ux/premium/README.md), recommendations R1–R11.

| # | Recommendation | Decision |
|---|---|---|
| R1 | Blue means "your call": the one blue button on a screen is always a decision only you make; chat Send becomes a dark (non-blue) control | **Accepted** |
| R2 | One inbox: the sidebar's Approvals folds into a filter on "What needs you" | **Accepted** (in the office: the "N need you" list is that one inbox) |
| R3 | One corner family (18 / 10 / pill), replacing DIRECTION rule 1's "8 px cards" | **Accepted** |
| R4 | The lowercase agent voice keeps real names and code as written ("Dana", "PR #41") | **Accepted** |
| R5 | "Needs you" counts leave out For-your-info items | **Accepted** |
| R6 | Atlas approves the preference notes agents learn about you by default, each shown with Undo and Forget | **Accepted** |
| R7 | Suggest a standing grant after 3 identical allows (never for outward or reserved actions); the same question covers exempting a routine from the 30 % guard | **Accepted** |
| R8 | At most 4 type sizes and 2 weights per view (drop the weight-300 subheads) | **Accepted** |
| R9 | No two agents on one screen share the same colour + form (in the office: per floor) | **Accepted** |
| R10 | First-run targets: Atlas's first reply < 3 min, first finished task < 5 min | **Accepted** |
| R11 | When the usage limit pauses a sprint, its end date doesn't move by itself; the lead proposes a new one | **Accepted** |

Still open for the client (brand stage 1, to present with direction v0.3): B-2 app icon, P-1 neutrals, P-2 action colour, P-3 typeface, P-4 Pear hue, P-5 continuous corners (R3 already covers the corner family), P-6 "Look inside" replaces "Trace" (the client asked to keep Look inside), P-7 sound.
