# CR-001: Manual projects, a team per project, customizable animated avatars

| Requested by | Date | Status |
|---|---|---|
| Client | 2026-10-22 | **Approved by direct instruction** (feedback round 1); BRD update pending |

- **Change:**
  1. The client can create a project manually (not only through CEO intake).
  2. The org tree belongs to each project: every project has its own Team view. The company level holds the CEO, the client's own agents and the projects.
  3. Agents get customizable, animated avatars (like Grok Bot / Dots).
- **Reason:** client feedback on prototype v0.2 (docs/requirements/interviews/2026-10-22-prototype-feedback-1.md).
- **Affected IDs:**
  - UC-43 (create a project: add a manual path)
  - UC-01 / UC-06 (the org tree is shown per project)
  - UC-02 / UC-04 (the agent card gets an avatar config)
  - UC-12 (CEO intake stays as the alternative path)
  - UC-26 (the dashboard sits inside a project)
  - PRD §6 / §9 (avatar work lands in the UI blocks)
  - UX IA and flows F2 and F10
- **Impact:**
  - Scope: small to medium; avatars add a customizer and animation states.
  - Schedule: absorbed in the existing sprints (avatars in the UI work of Sprint 2; the rest is navigation and IA).
  - Risk: low.
- **Decision:** applied in prototype v0.3. The BA updates the BRD to v1.1 and the PM updates the PRD at the next document pass.
