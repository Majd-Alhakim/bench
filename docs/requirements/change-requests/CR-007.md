# CR-007: You're only called for what matters

| Requested by | Date | Status |
|---|---|---|
| Client | 2026-10-23 | **Approved** (client's instruction) |

- **Client's words:** *"not everything needs me only major changes like deleting a repo or folder, payment, questions, something the agent were not able to decide; but merging and committing and these things happen automatically I am only called for testing"*
- **Change:** the set of things that need the client shrinks to:
  1. **Destructive actions:** deleting a repo, a folder or files outside an agent's own scratch area; deleting agents or projects.
  2. **Payments:** anything that costs money (agents still never pay; BR-58).
  3. **Questions:** an agent needs information only the client has.
  4. **Undecided decisions:** the team couldn't decide (debate timed out without a decision, the lead escalates).
  5. **Testing:** a finished piece of work is ready for the client to try (UAT), with what to test and how.
- **Now automatic** (no longer reserved): commits, pushes, opening and **merging PRs to main** (after CI is green and the independent reviewer check from CR-003 M3 passes), running tests and commands inside granted folders, routine work.
- **PM's reading, to confirm:** sending messages that speak **as the client to other people** (an email to someone else, a public post) still needs the client, because it acts outward in their name (BR-15). Merging and releasing inside the client's own repos does not.
- **Affected IDs:** BR-14, BR-15, BR-58 (reserved actions list), UC-22/UC-23 (approvals), CR-003 M3 (approval ladder: merge moves from "hand to the client" to "act if checks pass"), the "What needs you" ticket kinds (new: **Ready to test**; removed: merge / commit approvals), autonomy presets in agent Settings.
- **Impact:** fewer interruptions; the reviewer check and CI become the safety net for merges, so M3 must ship before auto-merge is enabled. Risk: a bad merge reaches main → mitigated by CI, the reviewer check, per-turn snapshots (M10) and easy revert shown in the trace.
