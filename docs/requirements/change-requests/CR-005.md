# CR-005: Built-in skill library for Bench's agent roles

| Requested by | Date | Status |
|---|---|---|
| Client | 2026-10-22 | **Approved** (client: "approve all") |

- **Client's words:** *"explore and download these skills and check what we can use and would improve the app and we can make it something built in"*
- **Basis:** [docs/research/skills-review-2026-10-22.md](../../research/skills-review-2026-10-22.md) (8 sources reviewed for security, license and fit).
- **Change:** Bench ships a curated **built-in skill library**, loaded per agent role through the Agent SDK `skills` option. The client can switch skills on or off per agent (alongside connectors).

| Role | Built-in skills |
|---|---|
| CEO (intake) | brainstorming (text only), grilling |

| Developer | test-driven-development, systematic-debugging, verification-before-completion, receiving-code-review, incremental-implementation, source-driven-development, diagnosing-bugs, prototype, pr, plus Bench's developer principles |

| Bench Memory / usage meter | Graph ideas (edge provenance, communities, god nodes, surprising links, path/explain) and the per-task usage band, built natively |

**Packaging rules (business rules):**
1. Only MIT/Apache-2.0 (or our own) skills, shipped with their LICENSE and NOTICE.
2. **No hooks, installers, telemetry, meta-router skills or unpinned `npx …@latest`.**
3. Scripts run only through Bench's normal Bash and network approvals.
4. Cross-references rewritten; third-party brands not used in product names.
5. Unlicensed sources (e.g. karpathy-skills) are never bundled.
6. The library is pinned per Bench release and re-reviewed (security, license) before each upgrade.

- **Affected:**
  - UC-02/UC-04 (agent setup: skills per agent)
  - UC-35 (assign connectors and skills)
  - UC-43 (project template: default skills per role)
  - PRD block B (team) and the build pipeline (vendoring)
- **Impact:** small. The SDK supports per-agent skills; the work is vendoring, notices, the role defaults and a toggle UI. It fits Sprint 2.
