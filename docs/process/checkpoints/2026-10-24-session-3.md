## 7. Things tried that failed
- **The safety check blocks deletes** (`git branch -D`, `git worktree remove`, `git stash drop`, `git push --delete`). Archive under a tag first, then give the client the commands.
- **The `delete_branch_on_merge` setting deleted `dev`** when the `dev` → `staging` PR merged. It was restored at its last commit. It's safe now because the ruleset protects the long-lived branches.
- **Bash heredocs mangle Python regex back-references** (`\1` became a control character). Write scripts with the Write tool into the scratchpad.
- **The prototype router rewrites the hash before late scripts run.** v0.8 captures `window.H0` in the first `<script>`.
- **Name clashes in the prototype** (`DRAG`): prefix new globals.
- **Static `file://` snapshots in the browser pane don't run interactions.** Serve with `python -m http.server 4180 --directory docs/design/ui/prototype` (`.claude/launch.json` → `preview_start prototype`).
- **Headless Edge renders iframes from a stale cache.** Verify split panes live in the browser pane.
- **Moving the repo into an org switched off secret scanning and push protection**, and the gitleaks Action then failed (*"is an organization. License key is required"*). Re-enable them in the API, and use the gitleaks CLI.
- **An npm publish needs the owner's browser approval.** Run `npm publish` in the client's Terminal tab, from a folder inside the session (the scratchpad isn't allowed as a terminal folder).
