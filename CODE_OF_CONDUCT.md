# Code of conduct

Eucas is a personal project shared openly. Everyone who joins in, in issues, pull requests or discussions, agrees to this:

- **Be kind and specific.** Critique the work, not the person. Say what's wrong and what would fix it.
- **Assume good intent,** and ask before assuming the worst.
- **No harassment,** no personal attacks, no discriminatory language, and no sharing other people's private information.
- **Respect the maintainer's calls** on scope and direction. Disagree openly, then let it go.

The maintainer may edit or remove content and block people who break these rules. Report problems privately to [@Majd-Alhakim](https://github.com/Majd-Alhakim) through GitHub.
